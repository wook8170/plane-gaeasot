# 시스템 아키텍처 및 데이터 흐름 분석 (System Architecture)

이 문서는 Plane.so의 전체적인 서비스 구조와 각 구성 요소가 어떻게 서로 연결되어 동작하는지 분석한 결과입니다.

## 1. 전체 계층 구조 (Layered Architecture)

System은 크게 4개의 핵심 계층으로 나뉘어 독립적이면서도 유기적으로 작동합니다.

### 1.1 주요 서비스 구성

- **프론트엔드 (Apps/Web)**: 사용자에게 보여지는 화면입니다. Next.js 프레임워크를 사용하며, 반응형 UI로 설계되었습니다.
- **백엔드 API (Apps/Api)**: 비즈니스 핵심 로직과 DB 연동을 담당합니다. Python 기반의 Django REST Framework(DRF)를 사용합니다.
- **실시간 동기화 서버 (Apps/Live)**: 문서 동시 편집과 같은 실시간 기능을 처리합니다. Node.js 기반의 Hocuspocus를 사용하여 데이터 충돌을 방지합니다.
- **백그라운드 워커 (Worker/Beat)**: 이메일 발송, 통계 계산 등 시간이 오래 걸리거나 비동기로 처리해야 할 작업을 담당합니다. Celery가 이 역할을 합니다.

---

## 2. 데이터 처리 흐름 (Data Flow)

사용자가 화면에서 수행한 액션이 실제 데이터로 저장되는 과정은 다음과 같습니다.

### 2.1 일반 요청 (REST API Flow)

1.  **사용자 브라우저**: UI에서 특정 요청(이슈 생성 등)을 보냅니다.
2.  **프록시 (Proxy)**: 모든 트래픽을 받아 처리합니다. `/api`로 시작하는 경로는 백엔드 서버로, 그 외 요청은 프론트엔드 서버로 전달합니다.
3.  **백엔드 컨트롤러 (Django View)**: 전달받은 요청을 해석하고 권한을 체크합니다. `apps/api/plane/app/views` 경로에 정의되어 있습니다.
4.  **데이터 검증 (Serializer)**: 입력된 데이터가 형식에 맞는지, 보안상 문제가 없는지 검사합니다.
5.  **데이터베이스 저장 (DB Model)**: 최종적으로 PostgreSQL 데이터베이스에 저장됩니다.

### 2.2 실시간 동기화 (Real-time Flow)

1.  **에디터 수정**: 사용자가 문서(Pages)를 편집하면 즉시 WebSocket을 통해 실시간 서버(`apps/live`)로 전송됩니다.
2.  **병합 알고리즘 (CRDT)**: 여러 사용자가 동시에 같은 곳을 고쳐도 데이터가 깨지지 않도록 병합합니다.
3.  **영구 저장**: 실시간 서버는 변경 내용을 주기적으로 백엔드 API를 통해 DB에 저장합니다.

## 3. 핵심 디렉토리 분석

### 3.1 백엔드 핵심 (`apps/api/plane`)

- `db/`: 데이터베이스 테이블 구조(Model)와 변경 이력(Migration)이 담겨 있습니다.
- `api/`: 외부 시스템과의 연동을 위한 공용 API들이 모여 있습니다.
- `app/`: 사용자가 사용하는 서비스의 핵심 기능 로직들이 포함되어 있습니다.

### 3.2 프론트엔드 핵심 (`apps/web`)

- `app/routes/`: 주소(Path)별 고유 화면 구성이 정의된 곳입니다.
- `core/store/`: 복잡한 UI 데이터를 효율적으로 관리하기 위한 상태 관리 로직들이 모여 있습니다.
- `core/services/`: 백엔드 API와 통신하기 위한 전용 함수 모음입니다.

---

## 4. 기능 확장 가이드 (개발 시 참고)

새로운 기능을 추가하거나 기존 기능을 수정할 때는 다음 순서를 따르는 것이 좋습니다.

1.  **데이터베이스 설계**: `apps/api/plane/db/models`에 필요한 테이블 구조를 정의합니다.
2.  **API 개발**: 백엔드에서 시리얼라이저와 뷰(View)를 만들어 데이터를 주고받을 통로를 엽니다.
3.  **비즈니스 로직**: 필요한 경우 `apps/api/plane/bgtasks`에 비동기 처리 로직을 추가합니다.
4.  **UI 연동**: 프론트엔드에서 `core/services`를 통해 API를 호출하고 화면에 데이터를 표시합니다.
